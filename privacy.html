What MoldStudio shares

Usage information, which holds no patient data, is sent by default; the first launch says so and offers a one-click off. A case is never sent on its own: only when you share it by hand, or when you have marked that case as having research consent on file. You can change any of this at any time under Help › Sharing and privacy.

Usage information

On by default since Alpha4, with a one-click off at the first launch and under Help. Used to improve the app. The app carries a built-in destination whose key can post usage files and nothing else; it cannot upload a case.

Sent

  • Which steps are built and approved, and how long builds take
  • What kinds of edits are made: paint, erase, cage, key pose
  • Plate verdicts, print jobs, error types
  • A random token for each case, which cannot be traced back to the case outside your Mac

Never sent

  • Scans or any geometry
  • Names, file or folder names, notes, free text
  • Dates, other than the time of each event

The format is an allowlist enforced in the app's code: anything not on it is dropped.

Shared cases

Opt-in, for research. By hand: choose Help › Share this case for research, review exactly what it contains, and confirm the patient's family has given the consent your clinic's agreement requires. Automatically: only for a case you have marked Research consent on file on the Case step; it is then shared after each plate is built or exported, with the same contents and the same checks. Ticking the box withdraws no approval, and untick it to stop.

Included

  • The scan geometry, the segmentation, the plan and key poses
  • Stage approvals, the plates and their reports
  • Diagnosis fields: LAHSHAL, side, arch, age in days
  • The order in which operations were done

Removed

  • Names, notes, override reasons and other free text
  • Scanner, file names and paths, the case id
  • Calendar dates, which become days after the scan

Before a package is written, it is searched for the case folder's name, the scan's file name and the painter, and refused if any is found.

Where it goes: usage files go to the MoldStudio team's inbox through the built-in destination, or to the destination your clinic enrolled with. A shared case goes only to your clinic's enrolled endpoint or to a folder your clinic chose under Help › Sharing and privacy, for example a synced Drive or OneDrive folder; without one, a shared case is saved as a file for you to send. The inbox is pulled to the team's own computer and emptied; nothing is kept in the cloud.

Updates

The app checks the MoldStudio release feed for new versions. The check carries no identifier and no data beyond an ordinary web request. An update is installed only if it is signed with the MoldStudio release key, matches its published checksum and passes macOS's code-signature check.
